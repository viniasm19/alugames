# 🎫 e-Ticket

Plataforma web para venda de ingressos, desenvolvida como projeto de estudo de HTML, CSS e JavaScript.

## 📋 Sobre o projeto

O e-Ticket permite escolher o tipo de ingresso (Pista, Cadeira superior ou Cadeira inferior), definir a quantidade desejada e finalizar a compra. Ao confirmar, o sistema valida se há estoque suficiente e atualiza a quantidade disponível de cada tipo em tela.

## 🖥️ Demonstração

![Preview do projeto](assets/Logo e-tricket.png)

O projeto conta com três tipos de ingresso:
- Pista
- Cadeira superior
- Cadeira inferior

## 🚀 Como executar

1. Clone o repositório:
```bash
   git clone https://github.com/viniasm19/e-ticket.git
```
2. Abra a pasta do projeto:
```bash
   cd e-ticket
```
3. Abra o arquivo `index.html` no seu navegador — não é necessário nenhum servidor ou instalação.

## 🛠️ Tecnologias utilizadas

- **HTML5** — estrutura da página
- **CSS3** — estilização e layout
- **JavaScript** — lógica de compra e manipulação do DOM
